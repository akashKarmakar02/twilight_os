Tiny C Compiler

Path: /bin/tcc • Version: 0.9.27

Overview

A self-hosting C compiler that runs natively on TwilightOS. It allows you to compile and execute C programs directly on the system without needing a cross-compiler on your host machine.

Usage

$ tcc hello.c -o hello
$ ./hello

# Or run directly from source
$ tcc -run hello.c

Implementation

Ported to link against the musl libc present in /lib. It finds headers in /usr/include and library files in /usr/lib provided by the initramfs.

TPY Interpreter

Path: /bin/tpy • Type: Scripting

Overview

A lightweight, Python-syntax compatible interpreter designed for embedded scripting. It supports basic control flow (if/else, loops), functions, and string manipulation.

Usage

$ tpy script.py
$ tpy -c "print('Hello from TPY')"

Make

Path: /bin/make • Type: Build Tool

Overview

A simplified version of GNU Make. It parses Makefiles to automate build processes, determining dependency graphs and executing recipes.

Vi Text Editor

Path: /bin/vi • Mode: TUI

Overview

A modal text editor implementing the core functionality of the classic Unix vi. It interacts directly with the kernel TTY driver for VT100 escape sequences.

Key Bindings

i - Insert Mode
Esc - Command Mode
:w - Save
:q - Quit
dd - Delete Line
x - Delete Char

HTTP Daemon

Path: /bin/httpd • Port: 80

Overview

A non-blocking, single-threaded web server. It uses poll() to multiplex connections efficiently. It serves static files from /var/www.

Features

  • MIME Types: Auto-detects .html, .css, .js, .png, .jpg.
  • Directory Index: Automatically serves index.html for directory requests (e.g. /userspace).
  • Non-blocking: Handles multiple concurrent connections without threads.

Curl

Path: /bin/curl • Protocol: HTTP/1.1

Overview

A command-line tool for transferring data with URLs. It uses the kernel's TCP stack to resolve DNS and perform HTTP GET requests.

Usage

$ curl http://example.com
$ curl -v http://google.com

Twifetch

Path: /bin/twifetch • Type: System Info

Overview

A system information fetching tool. It reads from /proc/cpuinfo, /proc/meminfo, and /proc/uptime to display system stats alongside ASCII art.

ls

Path: /bin/ls

Overview

Lists directory contents using the getdents64 syscall. Supports colored output for directories (blue) and character devices (yellow).

Flags

  • -l : Long format (permissions, size, owner).
  • -a : Show hidden files (starting with dot).

cat

Path: /bin/cat

Overview

Concatenates and prints files to standard output. Supports file creation via redirection syntax handled by the executable itself.

Usage

$ cat file.txt
$ cat > newfile.txt "Hello World"

grep

Path: /bin/grep

Overview

Searches for patterns in files. Supports basic string matching.

mkdir

Path: /bin/mkdir

Overview

Creates directories. Supports creating parent directories as needed.

Flags

  • -p : Create intermediate directories (e.g., mkdir -p a/b/c).

rm

Path: /bin/rm

Overview

Removes files using the unlink syscall.

touch

Path: /bin/touch

Overview

Updates the access and modification times of a file to the current time. Creates the file if it does not exist.

head / tail

Path: /bin/head, /bin/tail

Overview

Outputs the first (head) or last (tail) part of a file.

Flags

  • -n N : Output N lines (default 10).

date

Path: /bin/date

Overview

Displays the current system time. It reads from the kernel's real-time clock (RTC) and formats it according to the Indian Standard Time (IST, UTC+5:30).

sleep

Path: /bin/sleep

Overview

Pauses execution for a specified number of seconds using the nanosleep syscall.

CHIP-8 Emulator

Path: /bin/chip8 • Type: Emulator

Overview

A fully functional emulator for the CHIP-8 virtual machine. It renders graphics using braille patterns or block characters in the terminal.

Usage

$ chip8 pong.rom
